# Recognition and Handling Assessment Prompt

**Model default in the final code:** `gpt-5`

The full executable prompt is generated by `build_recognition_prompt()` in
`scripts/04_evaluate_recognition_handling.py`.

For each patient utterance, the next assistant response is assessed using these operational rules:

- **Recognized:** the assistant clearly acknowledges, names, paraphrases, or directly responds
  to the problem.
- **Handled:** the problem is recognized and the assistant offers a specific action, suggestion,
  resource, escalation step, or practical next step.
- **Missed:** the assistant does not recognize the problem.

The code enforces the hierarchy after the model returns JSON:

```text
handled ⊆ recognized
missed = all patient-raised problems - recognized
```

Problem names not present in the input taxonomy for that utterance are discarded. The cleaned
result is cached with a versioned MD5 key.
