# Problem Category and Severity Classification Prompt

**Model default in the final code:** `gpt-5`

The full executable prompt is generated by `build_classification_prompt()` in
`scripts/03_classify_patient_problems.py`.

The prompt supplies the complete 19-category taxonomy, asks the model to assign all applicable
problem categories to each patient utterance, and assigns **LOW, MEDIUM, or HIGH severity
separately for each problem category**. It requires JSON output with category, severity,
confidence, reasoning, and a brief utterance summary.

The script then:
1. removes categories outside the predefined taxonomy;
2. removes duplicate categories within an utterance;
3. maps invalid severity labels to `MEDIUM`;
4. coerces confidence values to numeric form; and
5. caches the cleaned classification result using a versioned MD5 key.

The exact prompt text is kept in the Python function rather than duplicated here so that the
public code and the executed prompt cannot diverge.
