# Aggregate results

These files were generated from the latest problem-specific evaluation outputs present in the
study analysis pipeline.

They are intentionally limited to aggregate, non-conversation-level results.

- `corpus_summary.csv`
- `recognition_summary.csv`
- `severity_distribution.csv`
- `severity_performance.csv`
- `severity_bootstrap_ci.csv`
- `problem_category_performance.csv`
- `human_evaluation_summary.csv`
- `human_evaluation_demographics.csv`
- `human_evaluation_coverage.csv`
- `human_evaluation_duplicate_conversation_ids.csv`
- `model_defaults_in_code.csv`

The raw human-evaluation export, full conversation-level outputs, and problem-level outputs are not included in this public release. The aggregate files are retained to make the principal reported quantities auditable without distributing restricted or record-level text.
